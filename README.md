## 🖥️ Running Locally

Clone the repository:

```bash
git clone <your-portfolio-repository-url>
cd <your-portfolio-directory>
```

Install the lightweight static development server:

```bash
npm install
```

Start the portfolio:

```bash
npm run dev
```

The portfolio will be available at:

```text
http://localhost:3000
```

You can also run:

```bash
npm start
```

## ☁️ Deployment

The portfolio is a static HTML/CSS/JavaScript website and can be deployed directly using platforms such as **Vercel**.

No backend server or database is required for the portfolio itself.
